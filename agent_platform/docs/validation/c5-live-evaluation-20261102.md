动态计划允许从冻结候选中缩小分工，因此三次运行的调用数分别为 3、4、4；没有强制为提升调用数而创建多余任务。规划费用与时间包含在动态团队结果中，固定团队包含两个成员及汇总的全部调用。

**默认仍使用单 Agent。** 这组简单的数值汇总任务中三种模式质量相同，单 Agent 的费用和延迟最低，没有证据支持将团队设为默认入口。固定团队与动态团队保留显式选择和功能开关；不因工程验收通过就自动切换普通会话，也不声称协作普遍提升质量。样本仅三种合成输入、每种模式一次，不能据此推断复杂业务、其他模型或重复运行的统计表现。

## 配置、预算与中断记录

- 使用已有配置的输入 0.30、输出 1.20 USD／百万 Token。这是项目固定参考价，未核实为 Wylon 的供应商发票价格；网关日志中的 `spend=0` 没有被当作免费调用依据。
- 将配置的 `PLATFORM_MAX_RUN_COST=1` 收紧为本次全部尝试的累计参考费用上限。完整九次运行花费 0.012386400000 USD；加上首次被会话中断的尝试，共 0.015906300000 USD，低于 1 USD。
- 首次尝试完成两组后，第三组的本地进程被会话中断。已有调用未自动重发；按配置凭据、模型及精确 UTC 时间窗口查询网关，得到唯一匹配的成功日志，记录其 1099 输入、2048 输出 Token。该调用的参考费为 0.002787300000 USD，前两组费用为 0.000732600000 USD。
- 中断调用没有完整本地输出，因此不计入质量或延迟对比；日志关联依据明确记录为凭据与时间窗口的唯一匹配，没有声称存在未实际传递的调用标签。保留[部分结果与费用核查记录](c5-interrupted-evaluation-20261102.json)，随后新建完整评估，累计预算减至 0.996480100000 USD。
- 评估脚本新增 `--env-file`，读取配置而不加载部署数据库；命令行可覆盖模型、价格和总费用上限。推理模型的评估输出上限从 2048 调整为默认 8192 Token，参数可在 128–16384 范围内调整。本轮完整九次采用相同模型、价格和 8192 输出上限。

所有 Agent、会话、余额和账本均在临时 SQLite 测试组织中创建，发送的只有合成数据。未修改正在运行的部署、原项目 `.env`、现有组织钱包或线上模型配置。
