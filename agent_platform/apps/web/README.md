# Agent Platform 控制台

React 19、TypeScript、Vite 构建的中文控制台。所有页面使用平台真实 API，没有内置演示数据或模拟模型回复。

## 启动

从本目录运行：

```bash
npm ci
npm run dev
```

开发地址为 `http://127.0.0.1:5173`，`/api` 默认代理到 `http://127.0.0.1:8000`。后端启动与初始管理员配置见 [平台说明](../../README.md)。如后端使用其他端口，可以设置 `PLATFORM_API_PROXY` 后启动 Vite，或将其写入本目录不提交的 `.env.local`。该变量仅供开发代理使用，不注入浏览器。

```bash
PLATFORM_API_PROXY=http://127.0.0.1:8010 npm run dev
npm run build
```

构建产物写入 `dist/`，由平台 API 同源托管。所有浏览器请求使用 `/api/v1` 相对路径，浏览器不持有 LiteLLM 或供应商密钥。

## 功能

- Cookie 会话恢复、登录、退出和修改密码；写请求携带 CSRF Token。
- 真实工作空间统计、模型分布、调用趋势与运行列表。
- Agent 草稿编辑、版本发布、模型与工具配置。
- 多轮会话、SSE 增量回复、工具执行事件、取消与断线重连；重连通过事件序号恢复，运行完成后读取持久会话快照。
- 模型定价、用户启停与角色管理、调用明细及 CSV 导出。
- 钱包、预占、暂停说明、人工入账与资金流水；管理员可根据证据确认待对账用量，或显式核销并记录原因。人工入账、人工对账和运行提交使用幂等键。
- 租户、用户、模型配额和累计预算策略；审计日志。
- 管理员与成员菜单、操作区分；成员可查看工作空间钱包与自己的调用明细，完整账本和人工财务操作仅管理员可见。服务端仍负责所有授权判定。

管理变更通过表单提交；账号和调用错误直接显示服务端返回的消息。未配置网关时如实展示状态，余额为零时需管理员显式入账。

## 界限

第一版使用基础会话文本展示，未加入 Markdown 富文本、工作流画布或文件上传。CSV 只导出当前已加载的调用记录；日期按设备时区展示，费用统一为 USD。配额预算为累计预算，不是自然月额度。

桌面控制台与窄屏布局共用页面；窄屏会话历史通过选择框切换。图表直接根据服务端聚合结果绘制，不依赖外部字体或图片服务。

## 浏览器验收

`npm run test:e2e` 使用隔离的无头 Chromium 与新浏览器上下文，覆盖真实 API 的登录、模型、Agent 发布、用户停用、人工入账、配额、审计、无网关拒绝与 390px 窄屏。它不会连接日常使用的浏览器。

验收会创建测试记录、增加测试额度并将租户 RPM 设置为 0，因此后端必须指向独立的临时测试数据库，而且不能配置真实模型网关。测试目标仅允许 localhost。准备测试服务后执行：

```bash
npm exec playwright install chromium
PLATFORM_E2E_PASSWORD_FILE=/absolute/path/to/test-password.txt npm run test:e2e
```

测试默认从平台的 `.data/browser-test-password.txt` 读取临时管理员密码，也可用 `PLATFORM_E2E_PASSWORD`、`PLATFORM_E2E_EMAIL`、`PLATFORM_E2E_BASE_URL` 配置。密码不会打印；测试不保留浏览器录像或请求 trace。截图位于不提交的 `test-results/`。

2026-09-22 验证记录：真实 API 服务运行于 `127.0.0.1:18080`，开发前端运行于 `127.0.0.1:5173`，使用独立 `browser-test.db`。`npm run build` 通过，Playwright **2 项端到端测试全部通过**，覆盖管理员完整操作链、成员管理入口与账本权限、成员停用后会话失效，以及 390px 窄屏导航、费用页、会话选择和无横向溢出。7 张桌面与移动端截图已生成并检查。

真实浏览器验证发现并修复了开发代理 Host 改写导致 Origin 校验失败的问题：Vite 显式保留浏览器访问 Host，后端仍严格校验请求来源；同时将表单标签改为明确的 `for/id` 关联，提示文本通过 `aria-describedby` 关联，确保下拉选择框具有稳定的可访问名称。

本次浏览器验收明确未配置真实模型网关，因此验证的是 `503 gateway_not_configured` 拒绝路径；真实供应商流式输出、工具响应和账单对账不在这次浏览器实测范围内。
